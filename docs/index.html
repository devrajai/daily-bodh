A widget that behaves like a daily ritual

Place it, forget it, and let it change by itself at midnight.

📜

Gita, in order

One shloka per day, in sequence, looping back after the end. Or pick any other pack.

🌑

Changes at midnight

A background job refreshes every widget after midnight, so the day’s content is always current.

🗃

Many widgets, many packs

Each widget on your home screen can show a different pack, language and colour at the same time.

🔠

Six ways to read

Original, transliteration, translation, 1-line summary, 2–3 line summary, or a 3–4 line bodh.

🎨

Full control

Background colour and transparency, shadow, corner radius, font colour, size, style and widget size.

📤

Favourite & share

Tap the widget for the full view, save favourites, and share any verse as an image.

Seven content packs, ready to grow

All content is plain JSON bundled inside the app. Add your own verses and thoughts without writing a line of code.

Install in three steps

  1. Tap Download APK above.
  2. Open the downloaded file. If Android blocks it, allow “Install unknown apps” for your browser or file manager, then tap Install.
  3. Open Daily Bodh, then long-press your home screen → Widgets → Daily Bodh.
Why a warning? This app is not distributed through an app store, so Android shows a standard caution for sideloaded apps. The APK is signed and contains no network permission.

Private by construction

No data is collected. Works fully offline.

  • The app declares no INTERNET permission — it physically cannot reach the network.
  • No login, no account, no sign-up of any kind.
  • No ads, no trackers, no analytics, no crash reporting.
  • All content ships inside the app; all your settings stay on your device.

Install & build

Most people just want the APK above. If you would rather build it yourself, or you want to change the content, the source is here.

Build the app from source

Open the project

Open the project folder in Android Studio (Koala 2024.1 or newer) with JDK 17.

Let Gradle sync

Android Studio downloads the build tools and dependencies on first open.

Build the APK

Press Run, or from the project folder in a terminal (use gradlew.bat on Windows):

./gradlew assembleDebug
# -> app/build/outputs/apk/debug/app-debug.apk

Install on your phone

With the phone connected over USB and debugging enabled:

adb install -r app/build/outputs/apk/debug/app-debug.apk

The README covers signing a release build and how to add your own content to the JSON packs.
