Gita, in order

One shloka per day, in sequence, looping back after the end. Or pick any other pack.

Changes at midnight

A background job refreshes every widget after midnight, so the day’s content is always current.

🗃

Original, transliteration, translation, 1-line summary, 2–3 line summary, or a 3–4 line bodh.

Private by construction

No data is collected. Works fully offline.

  • The app declares no INTERNET permission — it physically cannot reach the network.
  • No login, no account, no sign-up of any kind.
  • No ads, no trackers, no analytics, no crash reporting.
  • All content ships inside the app; all your settings stay on your device.

Install

Daily Bodh is built from source. There is no app-store download — the steps below produce the app on your own machine in a few minutes.

Heads up: a ready-made APK is not published here. Build it yourself from the project folder, or open it in Android Studio and press Run.

Open the project

Open the DailyBodh folder in Android Studio (Koala 2024.1 or newer).

Let Gradle sync

Android Studio downloads the build tools and dependencies on first open. Use JDK 17.

Build the APK

Press Run, or from the project folder in a terminal (use gradlew.bat on Windows):

./gradlew assembleDebug
# -> app/build/outputs/apk/debug/app-debug.apk

Install on your phone

With the phone connected over USB and debugging enabled:

adb install -r app/build/outputs/apk/debug/app-debug.apk

Add the widget

Long-press your home screen → Widgets → Daily Bodh → drag it out and pick a pack.

Full instructions, including how to sign a release build and how to add your own content, are in the project’s README.
