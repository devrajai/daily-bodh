What each build can do

I would rather tell you plainly than let a claim get stale. The offline build keeps the original promise exactly; the updater build trades a little of it for convenience.

 Offline buildUpdater build
Your contentFully offlineFully offline
SettingsStay on deviceStay on device
INTERNET permissionNoneYes — update check only
Network requestsImpossibleOne small version file a day, plus the APK when there is an update
Accounts / ads / trackersNoneNone
UpdatesYou download themChecked nightly, you tap to install

Neither build collects anything about you. The updater build talks to this site only to ask “is there a newer version?” and, if so, to fetch it.

Install

Download an APK

Pick the offline build or the updater build above.

Open the downloaded file

If Android blocks it, allow “Install unknown apps” for your browser or file manager, then tap Install.

Add the widget

Open Daily Bodh, then long-press your home screen → Widgets → Daily Bodh → drag it out and pick a pack.

If you chose the updater build

Allow notifications when asked. The first nightly check downloads any newer version and posts a notification — tap it to install.

Prefer to build it yourself, or change the content? The source is here.

Build the app from source 
./gradlew assembleOfflineDebug   # fully offline build
./gradlew assembleUpdaterDebug   # adds the nightly update check

The README covers signing a release build, the two flavours, and how to add your own content to the JSON packs.
