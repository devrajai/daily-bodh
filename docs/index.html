A widget that behaves like a daily ritual

Place it, forget it, and let it change by itself at midnight.

📿

Gita, in order

One shloka per day, in sequence, looping back after the end. Or pick any other pack.

🌗

Changes at midnight

A background job refreshes every widget after midnight, so the day's content is always current.

🗂️

Many widgets, many packs

Each widget on your home screen can show a different pack, language and colour at the same time.

🔤

Six ways to read

Original, transliteration, translation, 1-line summary, 2–3 line summary, or a 3–4 line bodh.

🎨

Full control

Background colour and transparency, shadow, corner radius, font colour, size, style and widget size.

📤

Favourite & share

Tap the widget for the full view, save favourites, and share any verse as an image.

Seven content packs, ready to grow

All content is plain JSON bundled inside the app. Add your own verses and thoughts without writing a line of code.

Bhagavad Gita — 700 shlokas, in order Business Leadership Self-Discipline & Willpower Be a Gentleman Motivation Inner Thoughts

Languages ship with English and Hindi, and adding another is a two-line change.

Private by construction

No data is collected. Works fully offline.

  • The app declares no INTERNET permission — it physically cannot reach the network.
  • No login, no account, no sign-up of any kind.
  • No ads, no trackers, no analytics, no crash reporting.
  • All content ships inside the app; all your settings stay on your device.

Install

Daily Bodh is built from source. There is no published APK download yet — the steps below produce one on your own machine in a few minutes.

Heads up: a signed APK is not hosted here yet. Clone the project and build it yourself (or open it in Android Studio and press Run). The whole app is open source.

Get the code

Clone the repository.

git clone https://github.com/devrajai/daily-bodh.git
cd daily-bodh

Build the APK

With JDK 17 and the Android SDK installed. Use gradlew.bat on Windows.

./gradlew assembleDebug
# -> app/build/outputs/apk/debug/app-debug.apk

Install on your phone

With the phone connected over USB and debugging enabled.

adb install -r app/build/outputs/apk/debug/app-debug.apk

Add the widget

Long-press your home screen → Widgets → Daily Bodh → drag it out and pick a pack.

Prefer Android Studio? Open the folder, let Gradle sync, and press Run. Full instructions, including signing a release build, are in the project README.
